# Construction Management System (CMS) — Frontend Web

Built for Sri Lankan Construction Industry (2026 PRD Compliant).

## Tech Stack
- **Framework:** Next.js 14 App Router
- **Language:** TypeScript
- **State Management:** Zustand (Slice Architecture)
- **Styling:** Tailwind CSS + Lucide Icons
- **Tax Compliance:** Sri Lankan IRD 18% VAT, EPF/ETF (8%/12%/3%), Progressive Tax

## Key Features Implemented
1. **Multi-Role RBAC:** Owner, PM, Site Supervisor, Labour Officer, Accountant, Store Keeper, Staff
2. **Project Management:** Project Card, Stage Lifecycle, Milestones, Daily Logs
3. **Inventory & Materials:** Category Tracking, PO Approval Thresholds (LKR 50k Owner Gate)
4. **Labour & Attendance:** Skill Trades, Daily Wages, Attendance Grid
5. **Payroll Engine:** EPF/ETF Calculation, PAYE Tax, Advance Recovery
6. **Sri Lanka Tax Module:** Emergency 60s IRD Tax Officer Mode Report Generator
